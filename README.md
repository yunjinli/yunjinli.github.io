# yunjinli.github.io

Personal academic site built on the [al-folio](https://github.com/alshedivat/al-folio)
Jekyll theme, with a custom portfolio homepage: short bio on the left, photo on
the right, standard navigation, and subtle motion.

- Adding news / publications / projects, homepage styling, and other
  site parameters: see [`CLAUDE.md`](CLAUDE.md).
- Local preview: `bundle exec jekyll serve --host 0.0.0.0 --port 4321 --livereload`,
  then open <http://localhost:4321/>.
- Original al-folio theme README (install/deploy instructions, general theme
  docs): see [`README_Orig.md`](README_Orig.md).
